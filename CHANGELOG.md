# Changelog

All notable changes to bfhttp will be documented here. The project follows
[Semantic Versioning](https://semver.org/) once release tags are published.

## [Unreleased]

### Added

- Complete eight-instruction Brainfuck interpreter with precomputed jump table
- Optional `!` host-call extension and documented memory ABI
- Native Node.js HTTP runtime with isolated request VMs
- CLI commands for running, executing, and compiling programs
- `.bfh` route preprocessor
- Hello, echo, query, and Brainfuck-powered login examples
- Vitest coverage for the interpreter, compiler, runtime, and HTTP layer
- GitHub Actions CI and community health files
