# Code of conduct

bfhttp is absurd; interacting with people here should not be.

Be respectful, constructive, and patient. Debate code and design decisions
without attacking people. Harassment, discrimination, threats, deliberate
disruption, and publishing someone else's private information are not
acceptable in project spaces.

Maintainers may edit or remove comments, commits, issues, and other
contributions that violate these expectations, and may temporarily or
permanently restrict participation when necessary.

Report conduct concerns privately to the repository owner. Reports will be
handled as confidentially as practical.
